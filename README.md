# Wayback Restorator

**Turn a Wayback Machine capture into a portable static website ZIP.**

Wayback Restorator restores archived pages and assets from the Wayback Machine, rewrites them for local use, and produces a self-contained static website archive with reports for missing captures and resumable restoration jobs.

## What it does

- Restores archived pages and assets using Wayback Machine captures.
- Rewrites HTML and CSS references for portable local use.
- Records missing captures instead of silently treating them as restored.
- Supports resumable restoration jobs.
- Produces a validated static website ZIP.
- Includes both a CLI and a local web dashboard.

For installation instructions, CLI usage, configuration, plugins, development documentation, and other details, see the [official documentation](https://docs.waybackrestorator.dev).
